Datenschutzerklärung

Sommerfest Kassa · Kassiersystem à la Nico Warscher

Kurzfassung

Die Sommerfest Kassa ist ein reines Kassier-Werkzeug. Es gibt kein Benutzerkonto, keine Anmeldung, kein Tracking und keine Werbung. Alle Kassendaten bleiben ausschließlich auf dem jeweiligen Gerät gespeichert und werden nicht an einen Server übertragen. Es werden keine personenbezogenen Daten von Kundinnen und Kunden erfasst.

Welche Daten werden verarbeitet?

Die App speichert nur das, was zum Kassieren nötig ist – lokal im Speicher des Geräts (Browser-„localStorage“ bzw. App-Speicher):

  • gewählter Verein (FSGL oder SCL)
  • laufende Bestellung, Tages- und Festsummen, Artikel-Stückzahlen
  • Wechselgeld-Startbetrag und Pfand-Stände
  • Einstellungen (z. B. Abend-Modus, PIN für die Auswertung)

Diese Daten enthalten keine Namen, Adressen, Zahlungsmittel oder sonstigen personenbezogenen Daten von Gästen.

Keine Weitergabe, keine Server

Es findet keine Übertragung an Server oder Dritte statt. Die optionale QR-Funktion erzeugt einen QR-Code auf dem Gerät selbst; die darin enthaltenen Zahlen werden nur übertragen, wenn du den Code bewusst mit einem anderen Gerät scannst. Es werden dabei keine Daten ins Internet gesendet.

Internetverbindung

Die App funktioniert offline. Eine Internetverbindung wird nur benötigt, um die App erstmals zu laden oder eine neue Version zu holen. Dabei werden die App-Dateien von GitHub Pages (GitHub, Inc.) ausgeliefert; dabei kann – wie bei jedem Website-Aufruf – technisch bedingt die IP-Adresse des Geräts verarbeitet werden. Es werden von der App selbst keine Analyse- oder Tracking-Dienste eingebunden.

Berechtigungen

  • Bildschirm wach halten: damit das Tablet beim Kassieren nicht in den Standby geht.
  • Vibration (optional): kurze Rückmeldung bei bestimmten Aktionen.

Es wird kein Zugriff auf Standort, Kontakte, Kamera-Aufnahmen, Mikrofon o. Ä. genutzt.

Deine Rechte & Löschung

Da keine Daten an uns übertragen werden, liegen alle Daten allein auf deinem Gerät. Du kannst sie jederzeit selbst löschen – über „Alles (Fest) zurücksetzen“ in der Auswertung oder durch Löschen der App bzw. der Website-Daten im Browser.

Diese Erklärung kann angepasst werden, wenn sich die App ändert. Es gilt jeweils die hier veröffentlichte Fassung.
