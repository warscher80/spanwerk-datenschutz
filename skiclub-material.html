📖 Firebase einrichten – Klick für Klick (einmalig, ca. 5 Min)
  1. Öffne console.firebase.google.com und melde dich mit einem Google-Konto an.
  2. „Projekt hinzufügen" → Name z. B. SkiClub Lienz → weiter (Google Analytics kannst du deaktivieren) → Projekt erstellen.
  3. Links im Menü Build → Realtime Database → Datenbank erstellen → Standort Europe → im Startmodus „Im Testmodus starten" → aktivieren.
  4. Menü Build → Authentication → Los geht's → Anonym auswählen → aktivieren → speichern.
  5. Oben aufs Zahnrad ⚙️ → Projekteinstellungen. Runterscrollen zu „Meine Apps" → auf das Web-Symbol </> klicken → App-Name eingeben → App registrieren.
  6. Jetzt zeigt Firebase einen Block const firebaseConfig = {…}. Diesen komplett kopieren und oben in Feld 1 einfügen.
  7. Vereins-Code in Feld 2 eintragen (auf Handy und PC exakt gleich), dann Verbinden.

Damit dauerhaft nur eure App zugreift, kannst du in der Realtime Database unter Regeln das hier einsetzen (dann sind Login-Konten nicht nötig, aber der Zugriff ist an die App gebunden):

{
  "rules": {
    "clubs": {
      "$code": { ".read": "auth != null", ".write": "auth != null" }
    }
  }
}

Hinweis: Die Daten liegen dann bei Google Firebase (kostenloses Kontingent reicht für einen Verein locker). Wer den Vereins-Code kennt, sieht die Liste – wähl also keinen offensichtlichen Code.
