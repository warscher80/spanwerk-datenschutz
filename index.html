Kurzfassung

Die App Spanwerk sammelt, speichert oder überträgt keine personenbezogenen Daten. Es gibt keine Konten, kein Tracking, keine Werbung und keine Weitergabe von Daten an Dritte. Die App funktioniert vollständig offline.

Welche Daten verarbeitet die App?

Spanwerk speichert ausschließlich deine Eingaben und Favoriten (z. B. zuletzt gewählter Werkstoff, Durchmesser, gespeicherte Schnittdaten) lokal auf deinem Gerät. Diese Daten verlassen das Gerät nicht und sind für niemanden außer dir zugänglich. Du kannst sie jederzeit löschen, indem du die App-Daten in den Android-Einstellungen leerst oder die App deinstallierst.

Internet & Berechtigungen

Für die eigentliche Nutzung (Schnittdaten, Maschinenstundensatz-Berechnung) benötigt die App keine Internetverbindung. Sie verwendet das Internet ausschließlich für eine optionale Update-Prüfung beim Start (siehe nächster Abschnitt) und fordert keine besonderen Berechtigungen wie Standort, Kontakte, Kamera oder Zugriff auf persönliche Dateien an.

Update-Prüfung

Beim Start prüft die App, ob eine neuere Version verfügbar ist. Dazu wird eine kleine Versions-Datei von GitHub (github.com bzw. github.io) abgerufen. Dabei werden keine personenbezogenen Daten übertragen; technisch bedingt kann GitHub als Server die IP-Adresse im Rahmen des Verbindungsaufbaus verarbeiten. Es findet kein Tracking statt. Lädst du ein Update herunter, holt die App die neue Installationsdatei ebenfalls von GitHub. Besteht keine Internetverbindung, funktioniert die App normal weiter – die Prüfung wird dann übersprungen.

Datenweitergabe an Dritte

Es findet keine Weitergabe statt. Es werden keine Analyse- oder Werbedienste eingesetzt.

Kinder

Die App ist für alle Altersgruppen geeignet und erhebt keine Daten von Kindern oder Erwachsenen.

Änderungen

Sollte sich an der Datenverarbeitung etwas ändern, wird diese Erklärung aktualisiert.
